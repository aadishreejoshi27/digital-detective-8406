> Git status = shows the current state of your working directory and staging area.
> Git add = moves the changes from working directory to the staging area 
> Git commit = takes everything in the staging area and creates a snapshot of the version history 
> Git log = reads the repo's commit history and displays it 

--> Task 6.4

> Git init creates a new, empty Git repository in the current folder by adding a hidden .git directory that tracks your project's history
> Git status shows which files are modified, staged, or untracked, and which branch you're on without changing anything
> Git add copies your changes into stagging area so that they can be included into the commit 
> Git commit -m saves everything into the stagging area as a snapshot of the version history 
> Git log shows the repo's commit history 
> Git branch lists all local branches 
> Git switch helps switch from one branch to another
> Git push uploads the commits to the Github repo
> Git fetch downloads the latest commits and branches from repo
