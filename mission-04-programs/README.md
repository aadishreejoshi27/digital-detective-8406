> The main difference between a complier and a interpreter is that a complier converts the entire program into machine code and then gives the output while an interpreter translates the code line by line into machine code and executes it as it translates. 

> An example of complier language is C and interpreter language is Python. 

> An advantage of complier is that it provides faster execution then interpreter because of better code optimization. 

> An advantage of interpreter is that it is easier to debug and test and is convient to use.
