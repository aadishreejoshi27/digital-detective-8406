> Process management is a way to manage all the currently running processes. example- let's say VS code and chrome are running simultaneously, the CPU will decide the amount of CPU time, memory and priority each task will get which is basically process management 

> Memory management is the way the OS manages the amount of memory each process will get in RAM. It also keeps track of memory usage of each of the process. taking the same example..let's say chrome needs more memory to load and upload images then the OS makes sure chrome gets the amount of memory it needs while making sure VS code gets enough memory too.

> Device management is the way the OS manages the hardward of the computer. It makes sure the devices are able to communicate properly with each other to ensure smooth execution of the running process because hardward and software work hand in hand. for example if one is using their macbook and have their headphones (wireless) connected to it.

> File management is the way the OS organises, modifies, deletes, and updates the files and folders on the system. 

> UI(user interface)/Shell are the parts of the OS which help the user interact with the system. They act like a bridge between the user and the system. 

> Security and Permissions are the way of the OS to help protect the user's data/files from any safety threats.
